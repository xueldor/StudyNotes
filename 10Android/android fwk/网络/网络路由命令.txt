问题分析：
ping -I eth1 192.168.225.1能ping通，不指定-I eth1，直接ping 192.168.225.1不能ping通。
1. 先ip route，确定已经有路由了。
2. ip route get 192.168.225.1
发现走的wlan
3. 所以ip route的路由没有生效
4. ip ru, 根据优先级，从上到下看每个表的路由
5. ip ru 发现缺了main表，即9000:   from all lookup main 这行
临时对策：
在init.rc里手动加上去，用ip rule命令:
ip rule add from all lookup main pref 9000

on property:sys.boot_completed=1
    exec - root root -- /system/bin/ip rule add from all lookup main pref 9000
宽容模式ok，打开selinux后保错：
init: Command 'exec - root root -- /system/bin/ip rule add from all lookup main pref 9000' action=hsae.route=1 (/system/etc/init/hw/init.rc:1258) took 0ms and failed: Could not start exec service: File /system/bin/ip(labeled "u:object_r:system_file:s0") has incorrect label or no domain transition from u:r:init:s0 to another SELinux domain defined. Have you configured your service correctly? 
指定selinx context即可，改成：
on property:sys.boot_completed=1
    exec u:r:su:s0 - root root -- /system/bin/ip rule add from all lookup main pref 9000

问题：
10500:  from all iif lo oif eth1 uidrange 0-0 lookup eth1 
11000:  from all iif lo oif wlan0 uidrange 0-0 lookup wlan0 
ip route get 180.101.51.73仍然走的wlan0。原因是oif eth1不匹配，去掉即可。可能连接指定了出口必须是wlan0，或者内核预估可能的出口不包含eth1。


代码：
APP内强制绑定wlan0
ConnectivityManager cm = (ConnectivityManager) getSystemService(Context.CONNECTIVITY_SERVICE);

// 构建网络请求：指定使用WiFi（对应wlan0）
NetworkRequest wifiRequest = new NetworkRequest.Builder()
        .addTransportType(NetworkCapabilities.TRANSPORT_WIFI) // 传输类型为WiFi
        .build();

// 构建网络请求：指定使用以太网（对应eth1）
NetworkRequest ethernetRequest = new NetworkRequest.Builder()
        .addTransportType(NetworkCapabilities.TRANSPORT_ETHERNET) // 传输类型为以太网
        .build();

// 注册网络回调，获取匹配的网络对象
cm.requestNetwork(wifiRequest, new ConnectivityManager.NetworkCallback() {
    @Override
    public void onAvailable(Network network) {
        // 当请求的网络可用时，获取该网络对象
        // 后续通信可绑定到该网络
        bindNetworkForCommunication(network);
    }
});
private void bindNetworkForCommunication(Network network) {
    try {
        // 示例1：使用Socket通信（绑定到指定网络）
        Socket socket = new Socket();
        network.bindSocket(socket); // 将Socket绑定到指定网络
        socket.connect(new InetSocketAddress("目标IP", 端口), 5000);

        // 示例2：使用HttpURLConnection（绑定到指定网络）
        URL url = new URL("http://目标地址");
        HttpURLConnection connection = (HttpURLConnection) network.openConnection(url); //通过network网络实例打开连接，而非直接url.openConnection()
        connection.connect();
    } catch (IOException e) {
        e.printStackTrace();
    }
}
