在多核处理器系统中，可以通过使用 `cpuset`，将特定的 CPU 和内存节点分配给进程或线程。

效果和前面介绍过的taskset指令类似。

taskset通常用于临时的、个别进程的 CPU 亲和性设置，不涉及对整个组的管理。

`cpuset` 允许用户在更高的层面上创建和管理 CPU 集合及内存节点，能够将一组进程绑定到特定的 CPU 上。通过设置 CPU 资源的限制，可以很方便地对一组进程进行管理。适用于长期的资源管理和隔离。

```shell
# 使用 mkdir 命令在 /sys/fs/cgroup/cpuset/ 目录下创建一个新的 cpuset
mkdir /sys/fs/cgroup/cpuset/my_cpuset
#向 cpuset.cpus 文件中写入要分配的 CPU 核心。例如，分配 CPU 0 和 CPU 1
echo "0-1" > /sys/fs/cgroup/cpuset/my_cpuset/cpuset.cpus
# 如果使用 NUMA，可以通过 cpuset.mems 来指定可用的内存节点
echo "0" > /sys/fs/cgroup/cpuset/my_cpuset/cpuset.mems
#向 cgroup.procs 文件中写入要添加的进程的 PID
echo "1234" > /sys/fs/cgroup/cpuset/my_cpuset/cgroup.procs
```
