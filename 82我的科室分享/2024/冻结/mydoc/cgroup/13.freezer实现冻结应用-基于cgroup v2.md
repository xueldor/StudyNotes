本节在CCS5.0上面演示通过freezer controller冻结进程。上一节cgroup V1的方法仍然是适用的，但是CCS5.0是安卓11，支持用V2来实现冻结。

1. `busybox vi /system/etc/cgroups.json`

打开文件看到有这段配置：

```json
"Cgroups2": {
  "Path": "/sys/fs/cgroup",
  "Mode": "0755",
  "UID": "system",
  "GID": "system",
  "Controllers": [
   {
     "Controller": "freezer",
     "Path": "freezer",
     "Mode": "0755",
     "UID": "system",
     "GID": "system"
   }
  ]
 }
```

表明5.0已经启用了freezer，并且是基于cgroup v2的。

到/sys/fs/cgroup目录确认存在freezer

2. 执行while :;do :;done&，模拟一个进程占用CPU100%。进程号是4966
3. `mkdir –p /sys/fs/cgroup/freezer/4966`, 目录名随意

4. 查看

   ```shell
   cd /sys/fs/cgroup/freezer/4966
   console:/sys/fs/cgroup/freezer/4966 # ls -l
   total 0
   -r--r--r-- 1 root root 0 2024-09-10 18:32 cgroup.controllers
   -r--r--r-- 1 root root 0 2024-09-10 18:32 cgroup.events
   -rw-r--r-- 1 root root 0 2024-09-10 18:57 cgroup.freeze
   -rw-r--r-- 1 root root 0 2024-09-10 18:32 cgroup.max.depth
   -rw-r--r-- 1 root root 0 2024-09-10 18:32 cgroup.max.descendants
   -rw-r--r-- 1 root root 0 2024-09-10 18:54 cgroup.procs
   -r--r--r-- 1 root root 0 2024-09-10 18:32 cgroup.stat
   -rw-r--r-- 1 root root 0 2024-09-10 18:32 cgroup.subtree_control
   -rw-r--r-- 1 root root 0 2024-09-10 18:46 cgroup.threads
   -rw-r--r-- 1 root root 0 2024-09-10 18:32 cgroup.type
   -rw-r--r-- 1 root root 0 2024-09-10 18:32 cpu.pressure
   -r--r--r-- 1 root root 0 2024-09-10 18:32 cpu.stat
   -rw-r--r-- 1 root root 0 2024-09-10 18:32 io.pressure
   -rw-r--r-- 1 root root 0 2024-09-10 18:32 memory.pressure
   ```

   只需要用到cgroup.freeze和cgroup.procs两个文件。

5. 冻结

   ```shell
   echo 4966 > cgroup.procs # 把4966这个进程添加到cgroup
   echo 1 > cgroup.freeze # 当前控制组状态设置为freeze
   ```

   然后通过top指令，检查进程CPU占用率是否为0。

6. 解冻

   ```shell
   echo 0 > cgroup.freeze
   ```

   然后top，可以看到已经恢复

   ![image-20241019200336367](./imgs/image-20241019200336367.png)

   当然，也可以通过把4966进程号移到外面，来实现解冻：

   ```shell
   echo 4966 > ../cgroup.procs
   ```

7. 回到上级目录（/sys/fs/cgroup/freezer/）,执行：`echo 1 > cgroup.freeze`。

   根据模型层级关系，所有子cgroup都会冻结，这时你再次到4966目录下，执行echo 0 > cgroup.freeze 不生效，不会解冻。
