1. wsl1和wsl2的主要区别是，wsl2有linux内核。而wsl1相当于把linux系统调用翻译成window的系统调用。

2. 使用wsl2, win10更新系统至1903或更高版本

3. 需要在“启用或关闭windows功能”里打开“适用于Linux 的windows子系统”、以及“虚拟机平台＂。bios开启虚拟化技术。

   cmd输入systeminfo命令查看是否支持虚拟化。

4. 打开后，vmware 15及以下版本不好用。把vmware升级到16或17即可。安装时界面有个用于支持同时运行wsl和vmware的复选框勾上。

5. 下载Linux内核更新包(wsl_update_x64.msi，不到20M,https://wslstorestorage.blob.core.windows.net/wslblob/wsl_update_x64.msi)

   or  `wsl --update`

6. 将 WSL 2 设置为默认版本`wsl --set-default-version 2`

   

   





## WSL 的基本命令

见https://learn.microsoft.com/zh-cn/windows/wsl/basic-commands

按顺序，先后要用到以下：

1. `wsl --set-default-version 2`

2. wsl --list --online

   ```
   C:\Users\yourname>wsl --list --online
   以下是可安装的有效分发的列表。
   使用 'wsl.exe --install <Distro>' 安装。
   
   NAME                            FRIENDLY NAME
   Ubuntu                          Ubuntu
   Debian                          Debian GNU/Linux
   kali-linux                      Kali Linux Rolling
   Ubuntu-18.04                    Ubuntu 18.04 LTS
   Ubuntu-20.04                    Ubuntu 20.04 LTS
   Ubuntu-22.04                    Ubuntu 22.04 LTS
   Ubuntu-24.04                    Ubuntu 24.04 LTS
   OracleLinux_7_9                 Oracle Linux 7.9
   OracleLinux_8_7                 Oracle Linux 8.7
   OracleLinux_9_1                 Oracle Linux 9.1
   openSUSE-Leap-15.6              openSUSE Leap 15.6
   SUSE-Linux-Enterprise-15-SP5    SUSE Linux Enterprise 15 SP5
   SUSE-Linux-Enterprise-15-SP6    SUSE Linux Enterprise 15 SP6
   openSUSE-Tumbleweed             openSUSE Tumbleweed
   
   ```

   

3. 根据2的结果，安装某个版本的linux,如：`wsl --install -d Ubuntu-24.04 `

   也可以通过 Microsoft Store 安装。

4. 查看本地已经安装的：

   ```
   C:\Users\xxx>wsl --list --verbose
     NAME            STATE           VERSION
   * Ubuntu-20.04    Stopped         2
     Ubuntu-22.04    Running         2
   ```

   

5. `wsl -d Ubuntu-20.04`进入Ubuntu-20.04。如果直接执行wsl，进入默认，即上面前面有星号的那个。用`wsl --set-default <Distribution Name>`设置default。

6. 把软件源换成阿里源：

   ```
   sudo sed -i s@/archive.ubuntu.com/@/mirrors.aliyun.com/@g /etc/apt/sources.list
   sudo sed -i s@/security.ubuntu.com/@/mirrors.aliyun.com/@g /etc/apt/sources.list
   sudo apt clean
   sudo apt update
   ```

   

8. 关闭 `wsl --shutdown`

   `wsl --terminate <Distribution Name>`

9. 导出导入分发版

   ```
   wsl --export <Distribution Name> <FileName>
   wsl --import <Distribution Name> <InstallLocation> <FileName>
   ```

    默认为 tar 格式

10. 装载磁盘`wsl --mount <DiskPath>`。比较复杂，使用时查询手册。

11. window磁盘映射在/mnt目录，默认就有：

    ```
    xue@YZ0500120190029:/mnt$ ls -l
    total 0
    drwxrwxrwx 1 xue  xue  4096 Sep 26 16:30 c
    drwxrwxrwx 1 xue  xue  4096 Sep 26 16:22 d
    drwxrwxrwx 1 xue  xue  4096 Sep 26 16:22 e
    drwxrwxrwt 2 root root   60 Sep 26 16:31 wsl
    drwxrwxrwt 8 root root  320 Sep 26 16:31 wslg
    ```

    可以手动mount一个目录：
    
    ```
    sudo mkdir /windowtmp
    sudo mount -t drvfs E:\\temp /windowtmp
    
    sudo umount /windowtmp # 卸载
    ```
    
    这样windows的E:\\temp目录就挂到了/windowtmp。需要主要ntfs的文件不支区分大小写，所以挂载过来后，linux同样把a和A认为同一个文件。
    
    问题：如何把wsl里的目录映射到wndows？
    
    可以创建一个vhdx格式的虚拟硬盘，然后挂载到ubuntu里。
    
    为了少记几个命令，我们通过windows的磁盘管理，创建。
    
    1. 点创建vhd，输入位置、大小、格式改为vhdx，动态扩展。
    
    2. 然后这个vhdx会出现在磁盘管理里面。我们把它分离。右击-分离VHD。不做这一步，文件会被windows占用。
    
    3. 选中vhdx文件，右击-属性-安全-高级，把所有者改成和ext4.vhdx一样的。否则mount到wsl里会报权限不足问题。如果还有权限问题，继续把组、用户名、权限都改成一样。
    
       （ext4.vhdx是wsl2安装好ubuntu后，系统盘的文件。参考下面“移到其它盘”）
    
    4. `wsl -d Ubuntu-22.04 --mount --vhd data_ext4.vhdx --bare`, 因为这个vhdx磁盘未经初始化，所以要加bare。我们当然可以在windows挂载，然后把它格式化为ext4格式，但是因为windows不支持ext4, 要用第三方软件。相比而言我们更熟悉linux命令，因此我先挂载到wsl里，用linux命令操作。
    
       卸载用“wsl -d Ubuntu-22.04 --unmount data_ext4.vhdx”。
    
    5. 也可以在windows里把这个vhdx装载到windows中，让window识别这个虚拟硬盘。然后wsl添加windows的磁盘（而不是像上面这样直接装载文件）。网上好多这是这种方案。但我觉得不方便，故不采纳。
    
    6. ubuntu里用lsblk命令看到硬件已经进来了：
    
       ```
       xue@YZ0500120190029:/mnt/e/wsl/ubuntu-22.04$ lsblk
       NAME MAJ:MIN RM   SIZE RO TYPE MOUNTPOINTS
       sda    8:0    0 388.6M  1 disk
       sdb    8:16   0     2G  0 disk [SWAP]
       sdc    8:32   0     1T  0 disk /snap
                                      /mnt/wslg/distro
                                      /
       sdd    8:48   0 878.9G  0 disk
       ```
    
       最后一个sdd即是。
    
    7. format成ext4格式：`sudo mkfs -t ext4 -i 12000 /dev/sdd`。
    
       我还希望把label命名为data。需要记更多命令用法。为了能少记忆命令，我们可以用gparted图形界面来格式化。参考下面GUI，如何运行图形界面。
    
    8. 把这个磁盘挂载到根目录的/data
    
       ```
       mount /dev/sdd /data
       
       #添加到/etc/fstab,让它能开机挂载
       vim /etc/fstab
       /dev/sdd    /data    ext4    defaults    0    0
       ```
    
       
    
    9. 完成。既可以在wsl里访问，可以通过windows的文件管理器访问。不过，通过windows访问大量小文件（如aosp），性能不佳，最好好像在wsl里面访问。

## 移到其它盘

默认在C 盘：

`C:\Users\xuexiangyu\AppData\Local\Packages\CanonicalGroupLimited.Ubuntu22.04LTS_79rhkp1fndgsc\LocalState\ext4.vhdx`, 

先导出，注销这个，然后导入到其它位置。

```
# 导出
C:\Users\xxxx>wsl --export Ubuntu-22.04 e://wsl//ubuntu-22.04.tar
正在导出，这可能需要几分钟时间。
操作成功完成。

# 注销
C:\Users\xxxx>wsl --unregister Ubuntu-22.04
正在注销。
操作成功完成。

#导入
C:\Users\xxxx>wsl --import Ubuntu-22.04 e://wsl//ubuntu-22.04 e://wsl//ubuntu-22.04.tar
正在导入，这可能需要几分钟时间。.
操作成功完成。

# 默认用户
# 通过`export`和`import`指令迁移WSL之后会发现进入系统的默认用户变成了`root`
打开`/etc/wsl.conf`配置文件，添加：
[user]
default=<user-name>
```
